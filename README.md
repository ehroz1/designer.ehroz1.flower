# ehroz.flower

Лендинг: сайты, интернет-магазины и Telegram-боты для цветочных магазинов Астаны.
Это статичный сайт на HTML, CSS и JS. Сборка и зависимости не нужны: сайт работает сразу, в том числе на GitHub Pages.

## Структура

```
index.html            — вся разметка и тексты
css/tokens.css        — дизайн-токены: цвета, шрифты, размеры, сетка, отступы
css/editorial.css     — вёрстка всех секций (только на токенах)
js/config.js          — контакты и настройки (менять здесь)
js/site.js            — меню, раскрытие фото, таймер, места, плавающая кнопка
assets/img/           — фотографии
assets/favicon.svg    — иконка вкладки
```

## Что поменять перед запуском

Откройте `js/config.js`:

```js
name: 'Эхроз',            // имя
telegram: 'hhrrzz1',   // ник в Telegram без @
whatsapp: '77775971798',  // номер WhatsApp, только цифры
phone: '77775971798',     // телефон для звонков
instagram: 'ehroz1',      // Instagram без @
spotsLeft: 5,             // сколько мест по акции осталось
```

Ссылки на Telegram и WhatsApp, подписи и счётчик мест обновятся по всему сайту.
Кнопки «Обсудить пакет» открывают WhatsApp с готовым сообщением «Цветы. Интересует пакет «…»».

## Фотографии

Промпты для генерации и нужные имена файлов собраны в [`assets/img/PROMPTS.md`](assets/img/PROMPTS.md).
Пока какого-то фото нет, на его месте показывается векторная заглушка в том же стиле. Фото можно добавлять по одному.

## Дизайн

Редакционная вёрстка в духе журнала: сетка из 12 колонок, один акцентный цвет (киноварь), без градиентов, теней и скруглений.
Цвет, шрифты и размеры меняются в одном файле — `css/tokens.css`.

Анимаций две: фото на обложке раскрывается до краёв экрана при прокрутке, а строка пакета заливается цветом при наведении.
Если у посетителя включено «уменьшение движения», они отключаются.

Цены со скидкой, число свободных мест и сроки акции стоят прямо в разметке, поэтому видны даже без JavaScript.

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**. Выберите ветку и папку `/ (root)`.
3. Через минуту сайт откроется по адресу `https://dsgn.ehroz.picta.cc/` (домен из файла CNAME).

## Локальный просмотр

Можно просто открыть `index.html` в браузере или запустить `npx serve .`.
